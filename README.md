# 🚀 Meu Portfólio Profissional Interativo

Este repositório contém o código-fonte do meu portfólio profissional estático, desenvolvido de forma individual como o primeiro grande marco de marca pessoal e consolidação de competências para a **Residência em TI**. 

O objetivo desta aplicação é estabelecer minha identidade digital profissional, servindo como uma vitrine de código, arquitetura de informação e competências práticas para *Tech Recruiters* e lideranças técnicas.

## 🎯 O Desafio & Alinhamento de Mercado
Conforme as diretrizes de mercado atual, ter competência técnica precisa estar aliado à visibilidade e credibilidade. Este projeto soluciona a padronização limitante de redes como o LinkedIn, entregando uma experiência personalizada com foco em:
*   **Abordagem Mobile-First:** Interface totalmente adaptada a partir de resoluções de 360px até desktops de 1280px+.
*   **Semântica Rígida:** Zero uso de frameworks CSS/JS. Estruturação nativa focada em SEO e acessibilidade.
*   **Performance:** Ativos digitais comprimidos e otimizados para carregamento instantâneo.

## 🛠️ Tecnologias Utilizadas no Portfólio
*   **HTML5 Nativo:** Estruturação semântica com uso rigoroso de `header`, `nav`, `main`, `section`, `article` e `footer` (Livre de "div-ite").
*   **CSS3 Puro:** Estilização responsiva estruturada via *Media Queries*, variáveis nativas (`:root`) e sistemas de layout modernos (Flexbox/Grid). **Zero frameworks** (Bootstrap/Tailwind).
*   **Formspree API:** Integração funcional e segura para o recebimento de mensagens diretamente na minha caixa de e-mail profissional sem a necessidade de um back-end proprietário.
*   **Google Fonts & FontAwesome:** Tipografia profissional (Inter) e iconografia vetorial de alta performance.

## 📊 Critérios de Qualidade Atendidos (Checklist de Aceite)
- [x] **Página Única (Landing Page):** Toda a experiência contida de forma fluida em uma estrutura simples de navegação por âncoras.
- [x] **Acessibilidade Básica:** Todas as imagens possuem o atributo descritivo `alt` e as taxas de contraste de cores atendem aos padrões de legibilidade.
- [x] **Otimização de Ativos:** Imagens comprimidas através de algoritmos do *TinyPNG* para mitigar o impacto no carregamento.
- [x] **Validação do Formulário:** Canal de contato 100% operacional conectado ao ecossistema do Formspree.
- [x] **Controle de Versão:** Fluxo de histórico transparente mantido com commits descritivos frequentes.
